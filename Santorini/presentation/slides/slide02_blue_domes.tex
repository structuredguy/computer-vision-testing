      \textbf{\color{aegeanblue}Structural Hierarchy \& Cultural Color:}
      \vspace{0.2em}
      \begin{itemize}
        \setlength{\itemsep}{0.2em}
        \item \textbf{Structural Load Path:} Hemispherical domes rest on barrel-vaulted naves via pendentives, transferring thrust directly down to massive perimeter masonry.
        \item \textbf{Merchant Navy Patronage:} The famous Oia chapels were primarily erected in the 1860s--1880s by affluent merchant captains.
        \item \textbf{The Cobalt Reality (\textit{Loulaki}):} Vibrant blue was originally achieved using \textit{loulaki}---an inexpensive laundry bluing powder mixed into slaked lime wash.
        \item \textbf{Modern Standardization (1967--1974):} The strict blue-and-white visual code was legally mandated by the Greek military junta to echo the national flag and curate Aegean tourism.
      \end{itemize}
    \end{column}
